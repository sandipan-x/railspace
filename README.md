# RailSpace

Baluster spacing calculator: get baluster count, even gaps and on-center layout that pass the 4-inch code rule, with diagram and cut list. Free tool.

## Features
- Baluster count, actual gap and on-center spacing with code compliance verdict
- To-scale elevation diagram with dimension labels
- Multi-section totalizer with waste factor and center-marking guide
